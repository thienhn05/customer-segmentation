# Customer Segmentation Dashboard

A production-ready Streamlit dashboard for customer segmentation using K-Means, Gaussian Mixture Models, and Hierarchical Agglomerative Clustering.

## Features

- Sidebar navigation with multiple pages
- Dataset overview and profiling
- Model comparison for multiple clustering approaches
- Interactive PCA visualizations
- Cluster summary and downloadable CSV exports
- Dark/light theme support
- Ready for Streamlit Cloud deployment

## Installation

```bash
pip install -r requirements.txt
```

## Run locally

```bash
streamlit run app.py
```

## Project structure

- `app.py` — main Streamlit app
- `prep.py` — data loading and preprocessing
- `GMM.py` — Gaussian Mixture Model analysis
- `hierarchical.py` — hierarchical clustering analysis
- `requirements.txt` — Python dependencies
- `.streamlit/config.toml` — Streamlit configuration
